# 幽灵的森林派对：操作与参数

项目版本：Unity 2022.3.62f3c1；Blender 4.4；Timeline 1.7.7；Cinemachine 2.10.7。本次没有升级 Unity 包。

## 开始游戏

从 `StartScene` 运行。标题页为 Blender 制作的静态森林派对主视觉，主按钮直接进入第一关。另有选关、设置和退出。旧视频文件保留在 `Assets/_Project/Videos`，启动场景不再绑定或播放视频。

第一关：找到栗栗、松松和团团，分别道歉，护送回野餐空地。可以一次护送一只，也可以三只同行。靠近狐狸按 E 交谈；和好后 E 可以切换跟随/原地等待。走得太远时狐狸等待，回到附近后继续；不会穿墙传送。

三只健康狐狸分别进入自己的聚会点后，播放团聚演出并打开选关面板。第二、三关保留食材和最终物品摆放目标。第一关原狐狸拾取对象被停用并以 `Archived_FoxPickup_` 标记，狐狸物品定义和预制体保留。

## 操作

| 输入 | 行为 |
|---|---|
| WASD | 移动 |
| E | NPC 对话/等待/跟随，或拾取、台面收放 |
| 长按 E 两秒 | 救起附近倒地的狐狸；离开或受伤会中断 |
| Tab | 打开/关闭背包，暂停游戏 |
| 点击背包格子 | 装备单件道具 |
| R | 收起手持道具 |
| 左键 | 使用道具，成功后减少一次耐久 |
| 右键 | 投掷整件道具，不回收 |
| Esc | 关闭背包 |
| 演出中长按 Esc 一秒 | 跳过演出 |
| 普通对话中 E | 补全文字或进入下一句 |

每局蝴蝶、番茄、芝士、白菜各三件，每件三次耐久。跨关保留背包、装备、血量、上限、护盾和加速剩余时间。重试本关重新发放初始物资和 5/5 血量，并跳过开场；返回标题结束本局。

玩家、狐狸和怪物均显示头顶名称及血条。番茄增加血量容器并回血，最多十血；狐狸五血，倒地可救，未找到及已到达的狐狸受保护。地图保持北向上，三角代表玩家，暖杏色标记狐狸，红色标记怪物，金色菱形代表聚会，浅色线框显示主相机地面视野。

## 公开参数位置

| 配置/组件 | 参数与默认值 |
|---|---|
| `KitchenObjectSO`，`Data/Items` | 耐久 3；普通投掷速度 12、距离 12、伤害 1、寿命 5；操作冷却 .25 秒 |
| 蝴蝶定义 | 速度倍率 1.5、持续 10 秒，重复刷新时间 |
| 番茄定义、`GameplayCatalog` | 回复/扩容 1；初始 5、上限 10；伤害保护 .75 秒 |
| 芝士定义 | 三层护盾、半径 1.4、环绕角速度 80 |
| 白菜定义 | 速度 10、距离 8、半径 3、伤害 1、兜底引爆 2 秒 |
| `FoxCompanion` | 五血；正常/追赶速度 5/8；落后 12 米等待，8 米内恢复；到达半径 2.5 |
| `FoxEscortQuest` | 交互范围 2.5 米、救援两秒 |
| `RockEnemy` | 三血；速度 3.5；感知 20、投掷范围 10；攻击间隔 2.5 秒 |
| `EnemySpawner` | 间隔三秒，同时三只，累计十只，出生半径两米 |
| `GhostMotionEffects` | 每米五团烟、最多 45 团、寿命 .85 秒、大小 .6、可调颜色；渐变参考高度 2.15 |
| `ForestLeaves` | 每区域每秒 .35 片、寿命八秒；地面落叶为静态合并网格，无碰撞 |
| `CircularMinimap` | 直径 240、半径范围 20 米、512×512 RT |
| `StoryCinematic` | 长按跳过一秒；电影画幅 2.35:1 |

## 编辑剧情、美术和声音

道歉配置位于 `Assets/_Project/Data/Story/Fox0Dialogue.asset` 至 `Fox2Dialogue.asset`。开场和团聚位于 `Assets/_Project/Timelines/ForestPartyIntro.playable`、`ForestPartyReunion.playable`。打开第一关，选择相应 PlayableDirector，再打开 Timeline，可修改 Cinemachine 镜头、角色走位、动画、音频、特效和字幕轨道。

走位轨道优先使用 `pathPoints` 中烘焙的导航转角；需要改路线时编辑该数组，或备份后重新运行配置工具。只改 `from/to` 不会覆盖现有导航路径。轨道注册了编辑器预览的位置和旋转属性，退出预览时由 Timeline 恢复。

幽灵可编辑源文件：`SourceArt/Ghost/ForestGhost.blend`；主视觉源文件：`ForestPartyTitle.blend`。建模、权重、烘焙动画和导出脚本为 `Tools/Art/create_forest_ghost.py`。Unity 仅使用 `Assets/_Project/Art/Models/Ghost/ForestGhost.fbx`，不会自动导入 `.blend`。控制器为 `Art/Animations/Ghost/ForestGhost.controller`，保留 `isWalking`，关闭 Root Motion。物理根节点与视觉悬浮分离。

运行 Blender 重建：

```powershell
& 'D:/Blender Foundation/Blender 4.4/blender.exe' --background --factory-startup --python Tools/Art/create_forest_ghost.py
```

音效由 `Tools/Art/create_party_audio.py` 原创合成，无游戏录音采样。音库位于 `Resources/ForestParty/AudioLibrary.asset`，混音器为 `Data/Audio/ForestParty.mixer`，暴露 `MusicVolume` 与 `EffectsVolume`。设置默认音乐 60%、音效 80%，实时应用并以 PlayerPrefs 保存。只持久化音量，不保存游戏进度。

UI 主题为 `Resources/ForestParty/UITheme.asset`，标题字体 ZCOOL KuaiLe，正文字体 Noto Sans SC。字体来源和 OFL 许可位于 `Assets/ThirdParty/ForestPartyFonts`。界面和音效为本项目制作，没有复制参考游戏素材。

作者配置入口：`Tools > Forest Party > Configure All Assets And Scenes`。此工具会重建本次生成的 UI、剧情和场景配置；手工编辑 Timeline 后应先备份，不要无意重跑。岩石怪物有独立模型、控制器和动画，不会被幽灵覆盖。
