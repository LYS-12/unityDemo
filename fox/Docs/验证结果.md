## 自动化运行测试

Test Runner 使用 EditMode 入口；其中三个流程用例通过 `EnterPlayMode` 实际进入游戏运行，再退出。其余为物品、会话、暂停、弹道和 JSON 规则测试。未把静态脚本检查写成 Play Mode 测试。

新增模型测试覆盖：初始四类各三件与唯一 ID、绑定场景不重复发放、装备/收起和整件移除、单件三次耐久耗尽、共享 SO 不受运行耐久影响、番茄扩容/回血/十血封顶、护盾上限/格挡/保护时间、加速刷新/到期、死亡只通知一次、重试重置、多个暂停所有者，以及公共弹道的落点和范围限制。

新增两项场景流程覆盖：

- 使用真实 Input System 动作注入 E、Tab、R、左右键；E 从真实狐狸来源入包，背包按钮事件装备，左键成功扣耐久，右键整件移除。
- 暂停时加速计时、刷怪数量和飞行弹体位置保持；关闭后恢复。UI 装备期间处于暂停，游戏攻击动作映射关闭。
- 真实台面往返保留同一个 `ItemInstance` 和剩余耐久；番茄使用后变为 6/6。
- 白菜经真实 Rigidbody 碰撞爆炸；给目标增加第二个碰撞体仍只扣一次血。普通弹体通过真实碰撞造成致死伤害并回池；为隔离树干遮挡，直接伤害测试使用目标上方的无遮挡发射位置。
- 池复用后的怪物重新为三血，存活最多三只，累计成功生成十只后拒绝继续生成；重复实例数不超过预热规模。
- 同时三只存活时明确拒绝第四次租用。NavMeshAgent 在实际环境中沿路径移动，路径长度缩短，并驱动实际 `isWalking` 动画参数。最终记录移动约 5.77 米，路径状态 Complete，包含六个拐点，见 `navigation-runtime-result.txt`。
- 怪物 AI 主动选择道具并发射，真实敌方弹体命中玩家、扣除护盾；怪物真实接触碰撞产生伤害。玩家阵营伤害被玩家忽略。
- 第一关到第二关保留会话、库存、上限、护盾和加速剩余时间。死亡暂停，重试恢复十二件初始物资与 5/5；返回菜单清空会话。
- 离开第一关后弹体池静态引用清理，导航三角形数量归零，未残留导航实例。

原有十二项测试继续通过：物品持有关系和缩放转移、两种 JSON 后端的用户保存优先/损坏回退/文件名约束、菜单与设置、三个关卡订单和摆放目标、完成返回、并发加载拒绝、输入订阅启停，以及重复进出场景的 Canvas/EventSystem/面板清理。

场景输入由虚拟键鼠设备驱动，背包格子和原面板按钮通过 Unity UI 事件入口触发；这不等于人工逐步通关。运行测试只隔离碰撞场景所需的随机位置和计时参数，未把测试修改保存回场景或预制体。

## 引用、复制资产与完整性

`GameplayValidation` 检查初始目录、六种定义的图标/预制体/拾取组件/战斗权限、Player 与 UI 动作映射、三关玩家组件和显式 Canvas 绑定，以及第一关刷怪器和狐狸锚点。导航检查在每个锚点半径内枚举候选，验证到玩家起始区域的完整路径；三个锚点分别有 10、6、1 个连通样本。运行时仍会检查占用和连通性，失败推迟，不计数。

怪物网格、Controller、动画片段均位于独立 Enemies 目录；动画片段名称与场景实际玩家一致，检查包含实际玩家对基础视觉预制体的 Controller 覆盖。岩石材质及纹理独立复制，原玩家、原动画和第三方资源不改。

Python 审计对照本局功能前文本备份和资源整理前基线：保留全部原 GUID，没有重复 GUID、缺失 `.meta`、丢失原场景/预制体引用，Packages 两个依赖文件保持原字节。功能前备份中的 484 个 GUID 全部保留。预期变化主要为自有脚本、游戏场景、物品定义与拾取预制体，以及碰撞层设置。

测试曾自动开启后台运行；最终已还原 `runInBackground: 0`，`m_TimeScale: 1`。构建使用还原后的设置。

## 复核与备份

保存并关闭同项目编辑器后执行：

```powershell
python Tools/validate_gameplay_assets.py
```

Unity 菜单 `Tools/Fox/Validate Inventory And Combat`、`Validate Project References` 和 `Build Windows Development Player`。命令行入口 `GameplayValidation.ValidateAndBuild` 可依次审计并构建；测试参数为 `-batchmode -force-d3d11 -runTests -testPlatform EditMode -testFilter FoxProject.Tests -testResults <绝对路径>`，测试不要附加 `-quit`。图形截图工具在普通图形编辑器执行 `-executeMethod GameplayVisualPreview.Run`，会重渲染图标、进入 Play Mode、导出画面并退出。
