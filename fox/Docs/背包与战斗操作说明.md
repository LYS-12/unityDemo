# 背包与第一关战斗

> 此页保留背包战斗阶段的说明。2026-10-22 已升级幽灵玩家、狐狸护送、头顶血条与剧情；当前操作和参数以 [森林派对操作说明](森林派对操作与参数.md) 为准。

Unity 2022.3.62f3c1；从 `Assets/_Project/Scenes/StartScene.unity` 运行，进入任一关卡。第一关包含怪物，第二、三关保留原有摆放玩法。

## 操作

| 输入 | 行为 |
|---|---|
| WASD | 移动，保持原有方向和动画 |
| E | 面向道具或来源台面拾取入包；空手收取台面物品；手持时向空台面摆放 |
| Tab | 打开或关闭背包，打开时暂停 |
| 点击背包格子 | 装备该件，之前的手持物自动收起 |
| R / 背包“收起手持” | 收回手持物 |
| 左键 | 使用手持道具，成功后扣一次耐久 |
| 右键 | 朝鼠标落点投掷整件道具，消耗整件 |
| Esc | 关闭背包 |

每局发放蝴蝶、番茄、芝士、白菜各三件，每件默认三次耐久。背包每格代表一件，手持标记仍属于同一列表；装备、收起、台面往返不恢复耐久。拾取立刻更新数量并显示提示。列表支持滚动，不限制容量。

狐狸与面包是任务物品，不在初始物资中；可以拾取、装备和摆放，不能使用或投掷。手持物和目标台面均已占用时不交换。重复来源仍可反复领取，一次性来源成功领取后失效。

## 效果和战斗

| 道具 | 左键使用 |
|---|---|
| 蝴蝶 | 移速变为 1.5 倍，持续十秒；重复使用刷新时间 |
| 番茄 | 血量上限和当前血量各增加一，最多十血；十血上限后只回血 |
| 芝士 | 增加一层环绕护盾，最多三层；每层完整抵挡一次攻击 |
| 白菜 | 发射一颗抛物线爆炸物，本体保留；伤害一，爆炸半径三米 |

满血且上限已达十时使用番茄、满三层时使用芝士，会显示原因且不扣耐久。普通右键投掷伤害一，白菜右键同样会爆炸。任务物品不参与战斗。投掷后不能回收。

玩家初始 5/5，左上角番茄容器显示血量，每行五个，失去的血量为暗色。接触怪物或被敌方道具命中均扣血；护盾先于血量结算。受伤或格挡后有 0.75 秒保护，期间不会继续消耗护盾。

第一关在三个狐狸来源点附近轮流寻找合法位置，每三秒尝试生成一只，最多同时三只，累计十只后停止。怪物三血，感知范围二十米，投掷距离十米，随机投掷四种基础道具。它们使用导航绕开障碍；出生区域被占用或无法连通玩家区域时延后尝试，不占累计额度。

死亡后暂停，可重试本关或返回菜单。重试重新发放初始十二件物资并恢复 5/5；返回菜单结束本局。死亡不自动存盘。

## 跨关与暂停

同一局切换关卡时保留背包、每件耐久、手持选择、血量与上限、护盾和加速剩余时间。加载与暂停期间停止计时；重新进入第一关会重开十只怪物的刷怪批次。选关与完成面板也会暂停，关闭相关面板或进入下一场景后恢复。

本功能没有磁盘存档。停止运行或返回菜单后，本局数据结束。

## 在 Inspector 调参

物品资产位于 `Assets/_Project/Data/Items`。运行时耐久属于 `ItemInstance`，不要修改共享 SO 来记录当前耐久。

| 配置位置 | 字段 | 默认值 |
|---|---|---|
| 各物品 SO | `maxDurability`, `actionCooldown` | 3，0.25 秒 |
| 各物品 SO | `throwSpeed`, `throwRange`, `projectileLifetime`, `throwDamage` | 12，12 米，5 秒，1 |
| Butterfly SO | `speedMultiplier`, `speedDuration` | 1.5，10 秒 |
| Tomato SO | `healthIncrease` | 1 |
| Cheese SO | `shieldLimit`, `shieldRadius`, `shieldOrbitSpeed` | 3，1.4 米，80 度/秒 |
| Cabbage SO | `explosionSpeed`, `explosionRange`, `explosionFuse` | 10，8 米，2 秒 |
| Cabbage SO | `explosionRadius`, `explosionDamage` | 3 米，1 |
| GameplayCatalog | `startingCount`, `initialHealth`, `healthCap`, `damageProtection` | 每类 3 件，5，10，0.75 秒 |
| RockEnemy 预制体 | `maxHealth`, `contactDamage`, `moveSpeed` | 3，1，3.5 米/秒 |
| RockEnemy 预制体 | `detectionRange`, `attackRange`, `attackInterval` | 20 米，10 米，2.5 秒 |
| 第一关 GameplaySystems / EnemySpawner | `totalLimit`, `aliveLimit`, `spawnInterval`, `spawnRadius` | 10，3，3 秒，2 米 |

最大护盾数还受玩法硬上限三层约束。字段带最小值约束；调整较大体型、出生半径或场景障碍后，应重新烘焙并验证导航。

`Tools/Fox/Configure Inventory And Combat` 是显式资源配置工具，会重新配置三关组件及导航，部分默认配置会重置。日常只调整已有资产，不需要反复运行。`Tools/Fox/Refresh Item Icons` 可重新渲染狐狸和蝴蝶模型缩略图。

架构、风险与验证证据见 [背包与战斗系统架构](背包与战斗系统架构.md) 和 [实际验证结果](验证结果.md)。
