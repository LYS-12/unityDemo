## 再次执行

Unity 菜单：`Tools/Fox/Validate Project References`、`Tools/Fox/Build Windows Development Player`。Test Runner：选择 EditMode 并筛选 `FoxProject.Tests`。

命令行可用以下模式等待 Unity 完成；测试参数使用 `-runTests -testPlatform EditMode -testFilter FoxProject.Tests -testResults <绝对路径>`，不要附带 `-quit`。引用检查和构建使用 `-quit -executeMethod ProjectValidation.ValidateReferences` 或 `ProjectValidation.BuildDevelopment`。

```powershell
$foxUnity = 'D:/unity/2022.3.62f3c1/Editor/Unity.exe'
$foxProject = 'D:/Desktop/WUgame/GitHubUnityDemo/fox'
$foxArguments = @('-batchmode', '-nographics', '-quit', '-projectPath', $foxProject,
    '-executeMethod', 'ProjectValidation.ValidateReferences',
    '-logFile', "$foxProject/Logs/reference-check.log")
$foxProcess = Start-Process -FilePath $foxUnity -ArgumentList $foxArguments `
    -WindowStyle Hidden -PassThru -Wait
$foxProcess.ExitCode
```

运行前保存并关闭使用同一项目的编辑器。使用此版本 Test Runner 跨越 EditMode/PlayMode 后，提交前应复核 PlayerSettings 的 `runInBackground` 是否仍为预期值。
